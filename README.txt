NTE ブロック自動組み Web版 v1

構成:
- index.html   画面構造
- styles.css   レイアウト・スマホ対応
- app.js       データ・自動配置計算・描画

特徴:
- Python / Tkinter 不要
- iPhone / Android / PC のブラウザで実行
- 外部ライブラリなし
- API通信なし
- 入力内容の外部送信なし
- 5x5盤面の計算はJavaScriptで端末内実行
- セット&希望ブロックは虹色表示

ローカル確認:
index.html をブラウザで開いてください。
一般的な静的Webホスティング（GitHub Pages等）にもそのまま配置できます。

注意:
現段階ではPWA（ホーム画面追加後の完全オフライン化）や自動更新機能は未実装です。


v2変更:

v4変更:

v6変更:

v7変更:

・タイトルは [NG] 選択設定
・NG選択は希望選択とは独立して最大8個まで保持
